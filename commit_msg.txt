feat: 集成原生离线 OCR、丰富截图标注与增强底层手势交互引擎

【业务视角】
1. 极致轻量化文字识别：基于 Windows 系统自带的 WinRT OCR 引擎实现离线图文识别，彻底摒弃了笨重的几十MB第三方模型库，不占用多余硬盘空间，秒级响应并原生支持中文等多语种。
2. 强大的截图与标注体验：在截图覆盖层中加入了高频刚需的“文字输入”功能与“调色板”支持，同时修复了工具条在特殊分辨率下的宽度错乱，让每次标注操作更加得心应手。
3. 高阶的手势定制能力：底层提供了内置命令分发以及暴露给 Lua 的 `easy.*` API，并在前端 UI 完成了针对“手势”与“作用域”的完整 CRUD 交互闭环，让高阶极客用户可以随意编排自动化流水线。

【技术视角】
1. WinRT API 深度整合：
   - 移除外部子进程方案，直接在 C++ 中引入 `Windows.Media.Ocr`，实现 `cv::Mat` 到 `SoftwareBitmap(Bgra8)` 的低开销近似零拷贝转换。
   - 在 `CMakeLists.txt` 中链入 `runtimeobject` 与 `winhttp`，保障 WinRT C++ 组件正常链接编译。
2. 底层按键合成 (SendInput) 重构：
   - 在 `GestureAction` 中重写 `KeyStroke::send` 方法，实现对组合修饰键的精准有序按下和逆序释放逻辑，彻底解决某些特定软件下组合键可能造成的键位卡死问题。
3. 截图管线增强：
   - CaptureOverlay 中实装了文字输入工具栏与相应的 UI 渲染分支，完善了此前的 UI 体验痛点，进一步解耦了截图底层事件流与上层标注逻辑。
4. Lua与内置分发器解耦：引入 `BuiltinCommandDispatcher` 负责原生功能调度，使 `GestureAction` 的核心执行流更为纯净。
