feat: 核心体验“世界级”全面升级与国际化支持

业务角度：
1. 交互体验跨越式升级：键盘热力图重构为全色谱渐变与动态光影特效；按键回显加入玻璃化边缘及入场弹性微缩放动效，视觉体验达到行业第一梯队水平。
2. 截图与标注专业化：截屏放大镜升级为双层高反差光环与精准十字准星；标注对象选中状态升级为 Figma 级深空蓝/纯白高质感控制手柄。
3. 国际化与用户体验设计：全软件完成 i18n 多语言适配，自动响应系统中英环境切换，确保任何语言环境下界面都不越界、无乱码；同时新增详尽的市场级对标调研报告与发布说明。

技术角度：
1. UI 渲染与样式工程：前端依托 i18next 架构建立语言管理系统；KeyboardHeatmap 采用纯 CSS3 backdrop-filter 与 HSL 坐标系进行函数映射，并利用 TSX 动态注入 CSS Variables，实现极低性能开销的丝滑动画。
2. C++ Direct2D 动效渲染：KeycastOverlay 中新增动画状态机，利用 SetTimer 高频抛出渲染事件，基于 D2D1::Matrix3x2F::Scale 计算缩放矩阵，完成淡入渐现与非线性缩放入场动画，并新增 0.1 透明度的 SolidColorBrush 描边。
3. OpenCV 标注底层改造：在 MarkupEngine 的绘制逻辑中，通过 cv::circle 与 cv::line 实现精确像素级的双环与准心计算；重构包围盒 (BoundingBox) 控制点的提取与绘制逻辑，使其支持高抗锯齿 (LINE_AA) 的嵌套绘制。
4. 并发与容错机制加强：修复 KeyboardHook、GestureEngine 中的同步隐患，增加 std::mutex 锁和强鲁棒性的 try-catch 拦截块，从底层保障即使抓取复杂键鼠操作也不出现钩子挂死现象。
