# EasyTools v1.0.2 官方正式版发布说明

EasyTools 是一款专为 Windows 平台打造的现代化、高能效、模块化桌面效率工具套件。采用 C++20 原生内核与现代 Web 技术驱动，融合文件对话框智能助手、高精度全局鼠标手势、全能截屏/长截图/录屏/离线 OCR、NTFS 毫秒级极速全盘搜索、按键回显 HUD 与轻量文件预览，兼具极致性能、高分屏自适应与人机工程学易用性。

---

## 🌟 v1.0.2 核心更新亮点 (What's New in v1.0.2)

### 1. 鼠标演示与特效 (Spotlight & Mouse Effects) —— 演示与教学的视觉利器
- **摇晃鼠标秒级唤醒，三大全屏聚焦动效直击视线**：
  - **「向心引力折叠」 (默认推荐)**：快速摇晃鼠标或按下快捷键，全屏双道高能光环高速向鼠标圆心收拢，伴随物理弹性微震与电影级深邃暗角，瞬间将全场观众或学生注意力牢牢锁死在鼠标光标处；
  - **「科技声纳雷达」**：光标原点向外激荡 3 道声纳脉冲光波，4 段战术 HUD 弧线刻度微旋磁吸锁定，极客科技感拉满；
  - **「极简极光涟漪」**：柔和贝塞尔暗角平滑浸润，光圈外缘溢出单道温和极光涟漪，舒适护眼不刺眼；
  - **更大更清晰的光圈**：聚光灯默认聚焦直径提升至 300px，即使在 4K 超高清大屏上也能清晰直观。
- **9×9 大师级动效矩阵**：
  - 点击鼠标时，提供星芒微粒迸发、彩色声纳微环、量子引力、特斯拉电弧、宣纸水墨、CAD 标尺、晨露气泡、超新星等 9 种灵动点击动效；
  - 移动鼠标时，提供流星拖尾、霓虹光线、彗星微粒等 9 种轨迹动效，拖动光标如行云流水。
- **120Hz/60Hz 丝滑无抖动**：接入高精度多媒体定时器管线，彻底消除动画卡顿与掉帧。
- **彻底根治免打扰铃铛误弹**：通过微型局部视口（100~300px）与 1px 物理几何避让，彻底根治此前 Windows 误判全屏而频繁在右下角弹出 `🔔z 专注助手（免打扰）` 铃铛的问题，且 GPU 显存与渲染开销骤降 99%。

### 2. 屏幕按键回显 (Keycast Overlay) —— 晶体键帽与极致清晰
- **半透明底色下，文字依然 100% 清晰锐利**：彻底解耦按键背景透明度与文字/图标渲染，就算把键帽背景调到半透明磨砂，按键文字与徽标依然实心饱满、字字分明，杜绝文字发虚发淡；
- **智能自适应对比度 (WCAG 2.2 AAA 级)**：内置智能亮度感知算法，在自动模式下遇到深色或半透明底色，自动匹配纯白高对比度文字，无论桌面壁纸如何变幻，始终一目了然；
- **物理晶体键帽设计**：重新调校所有按键的晶体键帽排版，彻底消除桌面文字透视穿帮与边缘溢出；
- **全面放行截图工具**：解除防截图限制，在录制视频或使用各类截图工具截取屏幕时，按键回显能被完美截取并纳入课件与教程中。

### 3. 托盘控制中心 (Tray Control Center) —— 2×3 对称快捷开关
- **一键掌控全局工具**：托盘菜单全新引入 2×3 对称快捷胶囊网格，鼠标特效（聚光灯）与对话框增强一键秒级启闭；
- **动态高度贴合与无缝重启**：托盘窗口根据内容自适应伸缩，修改核心配置后提供丝滑的重启提醒与一键热重载。

### 4. 开机自启动与权限管理 —— 稳定无感，免 UAC 烦扰
- **开机自启更稳定、隔离更彻底**：采用 Windows 原生任务计划机制为当前登录用户建立专属隔离通道，开机自启稳定可靠；
- **安装包开机自启选项**：安装包在向导中新增「开机自动启动 EasyTools」勾选项，无论安装还是卸载均能智能同步配置；
- **免 UAC 弹窗**：支持以最高权限开机静默启动，彻底摆脱每次开机都被 Windows 弹窗询问管理员权限的困扰。

### 5. 全局排版与无边框窗口 —— 细节质感飞跃
- **12px ClearType 次像素字字锐利**：重构全局排版令牌，全面消除全界面字体发虚、单薄与视觉割裂感；
- **全面拥抱矢量图标 (零 Emoji 规范)**：告别简陋的彩色 Emoji，全界面升级为高精度 Lucide 矢量 SVG 图标与玻璃拟态微胶囊；
- **设置窗口 8 方向自由拉伸**：无边框设置窗口全面支持四周及四角的流畅拖拽缩放，想放大看细节或缩小靠边放，随心所欲；
- **设置保存全局居中 Toast**：修改设置后屏幕居中弹出微型胶囊 Toast，1.8 秒后优雅淡出，再也不会出现 Toast 偶发卡死常驻的缺陷。

### 6. 全屏游戏与视频免打扰 (全模块标配)
- 鼠标聚光灯、按键回显、鼠标手势与快速文件搜索，全模块标配全屏全屏独占检测；
- 当你在玩 3D 全屏游戏或全屏看电影时，所有工具自动静默放行，零打扰、零误触。
