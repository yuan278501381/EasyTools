# EasyTools v1.0.4 官方正式版发布说明

欢迎体验 **EasyTools v1.0.4**！本次更新专注于**日常使用中的细微体感与操作直觉**。我们对文件对话框智能记忆、全盘搜索跟手度、按键回显视觉质感以及托盘交互进行了全方位的精细打磨，让每一次弹窗、搜索与快捷操作都更加自然、顺手、无感。

---

## 1. 智能文件对话框 (Dialog Enhancer) —— 零打扰、智能记忆与丝滑吸附

- **专属独立记忆，再次打开瞬间直达**：每个常用软件（如 VS Code、浏览器、办公套件、设计软件等）在打开或保存文件时，都能自动记住各自上一次实际确认使用的文件夹。再次触发文件弹窗时直接定位到目标目录，彻底告别在层层深文件夹中反复翻找；
- **智能防误记与父目录提炼**：只有在用户真正点击“打开”或“保存”确认后才会记录路径（取消或关闭窗口不会误记）；打开具体文件时精准提取所在目录，选择文件夹时停留在同级目标目录，路径定位永远符合直觉；
- **快捷悬浮胶囊生命周期强绑定**：顶部快捷悬浮工具栏（最近使用、与当前资源管理器同频、工作区置顶）仅在文件对话框处于前台时优雅呈现，切换到其他软件时自动隐退，彻底杜绝悬浮窗孤立残留或遮挡其他操作；
- **系统提示弹窗零误伤与原生兼容**：彻底消除对普通系统提示弹窗（如保存确认、错误提醒、MessageBox）的误判与干预，确保所有软件的原生弹窗 100% 稳定响应。

---

## 2. 全盘极速搜索 (Everything Instant Search) —— 灵动跟手与打字生理节奏自适应

- **人类打字生理节奏动态防抖**：在快速连续输入关键词时（如急促键入字母或拼音），搜索框智能感知打字节奏并无感合并查询请求；在停顿思索时（约 120ms）瞬间触发极速检索，打字手感极度轻快跟手，告别频繁检索带来的微卡顿与画面闪烁；
- **大体量全文检索前置保护**：当输入前缀较短时自动保护全文深层扫描，输入达到有效特征长度后才触发深度内容索引，检索效率大幅提升且不挤占后台资源。

---

## 3. 屏幕按键回显 (Keycast Overlay) —— 黄金字号与晶体半透明质感

- **默认 36px 黄金字号视觉呈现**：全新优化按键回显的基准字号与键帽间距，在大屏、高分屏及日常录课直播中呈现出恰到好处的饱满清晰度；
- **85% 默认晶体半透明质感**：优化整体不透明度渲染通道与初始参数，既能清晰醒目呈现按键组合，又保证背景内容若隐若现，不遮挡工作区核心内容。

---

## 4. 托盘控制中心与全局 UI 质感 (Tray & Unified UI)

- **220px 黄金紧凑宽度托盘菜单**：重调托盘控制中心弹窗宽度与弹性布局，右键菜单呼吸感更充裕，配置修改后的重启提示横幅自适应排版更舒适；
- **微晶数字步进控件 (Micro-crystal Stepper)**：全面替换设置界面中粗糙的原生数字输入框，带来带有微晶渐变、加减微按钮、平滑增减与防溢出边界的世界级数字调节体验。

---

## 5. 极速下载与安装体验

- **绿色便携包与官方安装器同步发布**：支持通过 Setup 安装包一键安装，亦可直接解压绿色便携版即开即用；
- **零系统字体污染**：所有界面文字采用系统原生渲染与应用内嵌字体栈，杜绝向 Windows 字体目录写入文件与注册表残留。
