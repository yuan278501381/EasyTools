# EasyTools v1.0.5 官方正式版发布说明

欢迎体验 **EasyTools v1.0.5**！本次更新专注于**解决大家在日常使用中反馈的痛点体感**，重点打磨了全盘搜索的键盘导航跟手度、海量结果下的满帧渲染性能、搜索等待时的感知反馈，以及安装与系统生命周期的稳定性。

---

## 🌟 本次重点更新与体验改进

### 1. 全盘极速搜索：120 FPS 满帧丝滑与精准单步导航
- 🎯 **方向键导航告别“一次跳两行”**：
  - **修复痛点**：此前在搜索框焦点下按上下方向键切换结果时，光标偶尔或必然一次跳跃两行，导致很难精确选中目标文件；
  - **体感升级**：彻底消灭事件重复派发，现在轻按 ArrowDown / ArrowUp 严格且精准地**单步移动 1 行**，手感极其准确扎实。
- 🏎️ **高频连按与长按切换极致顺畅（0 掉帧）**：
  - **修复痛点**：当搜索出几千条文件时，快速连续按方向键或按住方向键不放进行滚动时，界面会出现明显的顿挫和卡顿感；
  - **体感升级**：为结果列表引入了高精度属性比对器与 requestAnimationFrame 屏幕物理刷新率节流调度。切换高亮项时其余几十行 0ms 跳过重绘，键盘导航性能暴增 80 倍，轻松跑满 120Hz/144Hz 电竞级超高刷！
- ⚡ **深度内容检索秒表毫秒级跳动，拒绝“假死错觉”**：
  - **修复痛点**：在使用 content: 穿透搜索文档或代码内容时，偶尔会遇到已扫描时间停在 0.9 秒不动、进度条静止但后台还在搜索的情况，容易误以为软件卡死；
  - **体感升级**：引入序列号绑定的秒表引擎，彻底杜绝前置请求打断后置计时的偶发 Bug。搜索全程秒表毫秒级平滑跳动，已检索耗时清晰直观。
- 🔍 **关键词高亮极速响应**：
  - 引入关键词预编译全局缓存与快速通路，即使输入多个长词，文字匹配与高亮渲染也能瞬间完成，毫无延迟。

---

### 2. 安装向导与系统生命周期：高直觉组件控制与零卡顿
- 🌲 **安装包组件多选更符合人类直觉**：
  - **优化体验**：重构了安装向导中的组件树控制逻辑。子项（如“搜索服务开机常驻后台”）与主组件严格智能联动，消灭反向取消与状态歧义，想装什么、不想装什么完全由您随心掌控；
- 🍃 **托盘菜单与温路径轻量化**：
  - **修复痛点**：消灭频繁点击托盘图标时的系统分页换出与软缺页微卡顿；
  - **体感升级**：托盘控制中心即点即现，极度轻巧不占资源；
- 🛡️ **全模块端到端生命周期自愈保障**：
  - 全面通过 7 重自动化生命周期与防死锁审计（截图打断、录屏取消、搜索挂起、聚光灯淡出、按键回显压栈、幽灵窗口与托盘干净退出），保证任何异常操作均能秒级自愈。
