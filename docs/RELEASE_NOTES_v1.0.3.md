# EasyTools v1.0.3 官方正式版发布说明

EasyTools 是一款专为 Windows 平台打造的现代化、高能效、模块化桌面效率工具套件。采用 C++20 原生内核与现代 Web 技术驱动，融合文件对话框智能助手、高精度全局鼠标手势、全能截屏/长截图/录屏/离线 OCR、NTFS 毫秒级极速全盘搜索、按键回显 HUD 与轻量文件预览，兼具极致性能、高分屏自适应与人机工程学易用性。

---

## 🌟 v1.0.3 核心更新亮点 (What's New in v1.0.3)

### 1. 自由定制：安装向导 6 大功能模块按需选装 (Modular Installer)
- **纯粹自如，告别冗余**：全新安装向导支持在安装初始界面自由勾选 6 大核心模块（截屏标注、极速搜索、鼠标特效、按键回显、鼠标手势、对话框增强），按需定制专属轻量工具箱；
- **安装即用，偏好无缝继承**：首次启动自动同步你的模块偏好，无需在安装后再次逐项手动配置；
- **高分屏像素级对齐**：安装向导全面优化 4K / 2K 高分屏缩放适配，彻底消除多选框文字挤压与边缘截断。

### 2. 屏幕按键回显：黄金微晶实体键帽与智能防打扰 (Keycast Masterpiece)
- **1:1 实体微晶键帽美学**：全新 33px 紧凑外壳、1.45:1 优雅微晶底座与 Windows 11 微透视现代矢量微标，极具桌面现代质感；
- **打字智能静默，告别疯狂弹窗**：重构键盘状态机与 Shift 打字过滤算法，常规码字、写代码及中英文切换时自动智能静默，唯有快捷键操作才优雅呈现；
- **自由配色与智能自适应对比度**：修饰键底色支持自适应时下「主题色」，文字、背景与不透明度全面开放自定义，智能反差算法确保无论桌面壁纸深浅始终字字饱满锐利；
- **独立功能键 (F1~F12) 专属控制**：新增独立功能键细粒度开关，默认出现位置优化为视觉干扰最小的屏幕左上角。

### 3. 界面与排版：统一 3D 物理胶囊开关与全链路清晰字体 (Unified UI & Typography)
- **触觉级 3D 物理胶囊开关**：重塑全系统所有设置开关，具备微米级立体阴影、物理回弹动效与主题色流光渐变；
- **ClearType 次像素饱满字型**：建立统一应用级字体栈，支持界面字体智能选择与降级回退，彻底告别界面文字发虚、单薄；
- **微晶代码胶囊 (CodeBadge)**：窗口类名、进程名与文件路径全部包裹在精致的微晶等宽胶囊中，信息读取更清晰。

### 4. 极速全盘搜索：多关键词穿透与丝滑连打 (Search Precision & Penetration)
- **连续输入不再漏词**：彻底修复快速连续打字时光标收缩导致的多词跨路径文件无法匹配问题，搜索精准度与命中率大幅提升；
- **启动秒级响应**：优化搜索窗口预热调度与渲染就绪保护，呼出搜索框零闪烁、零失焦。

### 5. 沉浸式窗口交互与原生体验 (Window Navigation)
- **双击标题栏无级缩放**：设置等无边框窗口全面支持双击标题栏最大化与平滑还原；
- **原生右键菜单精准呼出**：标题栏右键物理光标绝对坐标定位，唤出 Windows 原生系统菜单；
- **全系统 151 个配置项 100% 稳定落盘**：底层 IPC 协议与持久化全覆盖加固，确保每一项设置改动都能实时保存生效。
